# E-Posta Asistanı

Bu proje, gelen e-postaları yapay zeka ile analiz edip sınıflandıran, gereksizleri (promosyon vs.) okundu olarak işaretleyen ve önemli olanlar için taslak yanıtlar oluşturan bir otomasyon sistemidir.

## Özellikler
- Belirli saatlerde (örneğin her sabah 09:00) otomatik çalışma
- Önemli/Gereksiz e-posta ayrımı
- Önemli maillere otomatik taslak yanıt oluşturma

## Kurulum
1. Gerekli kütüphaneleri yükleyin.
2. `.env` dosyasını kendi API anahtarlarınız ile güncelleyin.
3. `main.py` dosyasını çalıştırın.
